## 📌 Project Overview
The **Library Management System** is a complete Python application engineered to streamline catalog management, patron memberships, book loans/issues, returns, and overdue fine calculations.

---

## 🚀 Features
- 📖 **Book Management:** Track inventory, total copies, available stock, and borrow frequency.
- 👤 **Member Management:** Enforce max borrowing quotas and track active loans.
- 🔄 **Issue & Return:** Automatic 14-day due date computation and overdue fine calculation.
- 🔍 **Search & Filter:** Find books by Title, Author, ISBN, or Category.
- 📊 **Library Analytics:** Statistics on top borrowed books, active loans, and fine revenues.
- 🧪 **Unit Tests:** High test coverage with `pytest`.
- 📄 **PDF Project Report:** Automated PDF report generated using `ReportLab`.

## 🛠️ Installation & Execution

1. **Navigate to directory:**
   ```bash

   ```
2. **Install requirements:**
   ```bash
   pip install -r requirements.txt
   ```
3. **Run Application:**
   ```bash
   python main.py
   ```
4. **Run Tests:**
   ```bash
   python -m pytest tests -v
   ```

