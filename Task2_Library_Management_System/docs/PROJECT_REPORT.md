## 1. Executive Summary
The **Library Management System** provides an organized software solution for cataloging books, tracking patrons, issuing loans with automatic due dates, processing returns, and calculating overdue fines.

---

## 2. Key Features
- **Book Management:** Manage books by ISBN, title, author, category, total copies, and available stock.
- **Member Management:** Register patrons, track currently borrowed books, and enforce borrowing quotas.
- **Issue & Return Workflow:** 14-day default loan period, transaction IDs, stock checks, and automatic fine calculation ($2/day overdue).
- **Search & Filter:** Search by book title, author, ISBN, or genre.
- **Analytics:** Popular books leaderboard, loan distribution, and financial reporting.
- **Automated Tests:** Comprehensive unit test suite with `pytest`.
